# 🐦 HexSoftwares | Tweet Sentiment Analysis (NLP + Machine Learning)

## 📌 Project Overview
This project is a Machine Learning and Natural Language Processing (NLP) based web application developed under **HexSoftwares**. It analyzes tweets and classifies them into **Positive 😊, Negative 😞 (and optionally Neutral)** sentiment using trained ML models. The system performs end-to-end text processing, feature extraction, model training, evaluation, and real-time prediction through an interactive Streamlit dashboard.

---

## 🚀 Key Features
- 🔍 Real-time sentiment analysis of user input tweets  
- 🧹 Advanced text preprocessing (URLs, mentions, hashtags, punctuation removal)  
- 🧠 Stopwords removal and clean text normalization  
- 📊 TF-IDF based feature extraction  
- 🤖 Multiple ML models implemented:
  - Logistic Regression  
  - Naive Bayes  
  - Support Vector Machine (SVM)  
- 📈 Model performance comparison with accuracy scores  
- 🎛️ Interactive Streamlit dashboard UI  
- 💡 Sample tweet auto-suggestion buttons for easy testing  
- ✨ Animated and modern UI design for better user experience

## 📊 Model Performance Summary
- Logistic Regression → ~71% Accuracy  
- Naive Bayes → ~69–75% Accuracy  
- Support Vector Machine (SVM) → ~75–80% Accuracy (Best Performing Model)
